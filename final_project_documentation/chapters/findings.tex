The ingress host is \texttt{shoy.publicvm.com}, with a TLS block referencing a

\texttt{ClusterIssuer} using the HTTP-01 solver through the NGINX ingress class,
so \texttt{shoy-tls-secret} is issued by Let's Encrypt rather than created by hand
(Section~\ref{sec:bootstrap-pipeline}).

\section{Scaling and Resource Allocation}\label{sec:scaling-resource-allocation}
\begin{warningbox}[Autoscaling Configuration]
The Helm chart (\texttt{helm/ecommerce-app/templates/hpa.yaml}), which ArgoCD
reconciles, scales every workload on CPU utilization only, at 75\%. The raw manifest
(\texttt{kubernetes/06-hpa.yaml}) scales the same workloads on both CPU (75\%) and
memory (80\%). Table~\ref{tab:hpa-actual} shows the Helm policy, since that is the
one GitOps keeps live.
\end{warningbox}
